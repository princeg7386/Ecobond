EchoBond - run it on your laptop
================================

This is the same EchoBond website as the shared link. It runs entirely in your
browser on a FICTIONAL example family. No server, no API keys, no internet needed.

HOW TO RUN (needs Python 3, which most laptops have; get it from python.org if not):
  Windows:      double-click  start-windows.bat
  Mac / Linux:  open Terminal in this folder and run  ./start-mac-linux.sh
Then open http://localhost:8080 in Chrome or Edge (it opens automatically).
Keep the black window open while you use it; close it to stop.

Please don't just double-click index.html: browsers block photo checks and the
camera on file:// pages, so face recognition won't work that way.

No Python? If you have Node.js instead, run  npx serve .  in this folder.
